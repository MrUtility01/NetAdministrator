# NetAdministrator Android — دانشنامه جامع شبکه

نسخهٔ بومی اندروید برای مطالعه و مرور آفلاین محتوای برنامهٔ Windows NetAdministrator.

## قابلیت‌های موجود در سورس

- اتصال به میزبان ویندوز از طریق آدرس دستی و رمز شش‌کاراکتری
- همگام‌سازی فصل‌ها با بررسی هش SHA-256
- ذخیره محلی با Room
- تقویم شمسی برای کارها و مرور
- رابط Jetpack Compose
- نشست امن با AES/GCM و Android Keystore

برای جزئیات کامل به README.md و پوشه docs مراجعه کنید.
