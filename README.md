# NetAdministrator Android — دانشنامه جامع شبکه

کلاینت بومی اندروید برای برنامهٔ Windows NetAdministrator. فصل‌ها از سرور ویندوز در شبکهٔ محلی همگام می‌شوند و پس از دانلود در پایگاه Room نگه‌داری می‌شوند تا مطالعه، کارت‌ها، آزمون، جست‌وجو و برنامه‌ریزی بدون اینترنت ادامه یابد.

- رابط: Kotlin + Jetpack Compose
- پایگاه محلی: Room
- همگام‌سازی: OkHttp + SHA-256 + نسخه‌بندی فصل
- نشست همگام‌سازی: کوکی `nl_session` رمزگذاری‌شده با AES/GCM و Android Keystore
- تقویم: نمایش و ورود تاریخ شمسی
- کارها: محلی و مستقل از ویندوز
- پشتیبان: ZIP شامل پایگاه، تنظیمات و رسانه‌ها

## ساخت در GitHub Actions

Workflow در `.github/workflows/android.yml` آزمون واحد را اجرا و APK آزمایشی را به شکل Artifact قرار می‌دهد. اگر tag با الگوی `v*` push شود، `.github/workflows/release-apk.yml` یک Release با APK آزمایشی می‌سازد.

## ساخت محلی

نیازمند JDK 17، Gradle 8.13 و Android SDK Platform 36 / Build Tools 36 است:

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## اتصال به ویندوز

در Windows NetAdministrator نسخهٔ 0.4.5 سرور همگام‌سازی شبکهٔ محلی را فعال کن. در صفحهٔ تنظیمات اندروید آدرس میزبان مانند `http://192.168.1.20:8000/` و رمز شش‌کاراکتری را وارد و «اتصال / همگام‌سازی تغییرات» را انتخاب کن. HTTP فقط برای شبکهٔ خصوصی و مورداعتماد است؛ سرور را به اینترنت عمومی باز نکن.

## محدودیت‌های روشن

- سورس و CI آماده شده‌اند، اما APK در محیط حاضر build نشده؛ این محیط Android SDK/Gradle و دسترسی شبکه برای دریافت dependencyها نداشت. قبل از نصب نهایی باید CI موفق شود.
- اتصال در نسخهٔ فعلی با IP و پورت دستی است؛ کشف خودکار mDNS/NSD هنوز اضافه نشده.
- جهت انتقال محتوا Windows → Android است. کارها، برنامه‌ریزی و مرور به‌صورت محلی ذخیره می‌شوند و به Windows برنمی‌گردند.
- این برنامه DRM نیست؛ محتوای دانلودشده روی دستگاه تحت کنترل کاربر است.
- برای دستورهای انتشار و جزئیات آزمون، `docs/` را ببین.
